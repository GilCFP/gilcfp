### Project Spotlight: [FairSet](https://fairset.com.br/) — Volleyball Platform &amp; Analytics

**FairSet** is an active volleyball platform with **800+ active users**, available natively on **iOS (App Store)**, **Android (Google Play)**, and **Web**. Engineered for casual matches (*peladas*), competitive teams, practices, and championships.

| Capability | Description |
| :--- | :--- |
| **Match Scoring &amp; Súmulas** | Real-time live scoreboard with device concurrency locking for practices, official championship scoresheets (*súmulas* with rotations, substitutions, sanctions, and timeouts), and offline scoring support. |
| **1v1 Duels &amp; TrueSkill** | Post-match player evaluation engine based on pairwise 1v1 confrontation duel voting aggregated into a calibrated, zero-sum TrueSkill rating algorithm. |
| **Team Treasury &amp; Finances** | Complete team cash flow management, monthly membership tracking (*mensalidades*), and automated payment processing (PIX / Credit Card) via Asaas. |
| **Gamification &amp; Progression** | XP-driven level progression algorithm, difficulty-ranked team missions, custom badge awards, and position-specific skill tracking across all 6 volleyball roles. |

### Systems Engineering &amp; Architecture Highlights

- **Mobile-First Hybrid Architecture:** Single codebase React/Vite web application built with Capacitor targeting native iOS and Android deployments.
- **Serverless &amp; Cloud Scheduling:** NestJS modular backend deployed on Firebase Functions with asynchronous, OIDC-authenticated background workflows coordinated via Google Cloud Tasks.
- **Data Modeling &amp; Persistence:** Relational schema design with PostgreSQL and Prisma ORM, optimized connection pooling, and resilient transaction boundaries for billing and duels.
